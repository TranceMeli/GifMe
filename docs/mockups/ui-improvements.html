    Delete “Mind blown”?

    The GIF and its files are permanently removed from this computer. This cannot be undone. Only want it to look different? Editing is the better choice.

    1. 1
      A path instead of just "Back"The hierarchy is flat, but the path "Collection / GIFs / Title" shows where you are and leads back to the filtered list. NNG, breadcrumbs support orientation
    2. 2
      One main actionOnly "Copy to clipboard" is orange, everything else is secondary. Figma and Microsoft, hierarchy and contrast
    3. 3
      Feedback with icon and wordSuccess with a check mark, errors with a warning triangle and the word "Error". Today an error differs only by color. W3C Use of Color
    4. 4
      Make autosave visibleOne sentence explains saving on leaving a field, "(optional)" marks every optional field instead of asterisks. Nielsen, heuristic 1; Baymard, label optional fields
    5. 5
      Delete set apartEdit and Delete are separated, Delete sits on the right with spacing and a dashed divider. Prevents accidental clicks. Nielsen, heuristic 5
    6. 6
      Delete dialog with an alternativeThe dialog names the title, says "cannot be undone" and offers "Edit instead", matching your wish. Focus starts on "Cancel". Nielsen, heuristics 3 and 5

      Rule for the code: muted text and the danger color never sit on orange or blue. Only the normal text sits on orange and blue. The orange panel border (2.1 : 1) is decorative; all operable fields use the dark border.
